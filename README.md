# Brio Music Studio · Інтерактивна клавіатура фортепіано

Навчальний вебзастосунок для дорослих: групи чорних клавіш, будиночки клавіш, октави та інтерактивні вправи. Мови: українська, російська й англійська.

## Публікація

Сайт налаштований для GitHub Pages за адресою https://briomusicstudio.github.io/keyboard-adults/.

1. Завантажте файли проєкту в корінь репозиторію `keyboard-adults`.
2. У GitHub відкрийте **Settings → Pages**.
3. У розділі **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`.
4. Після публікації переконайтеся, що сайт відкривається за HTTPS, а сторінки й зображення завантажуються.
5. За бажанням додайте `https://briomusicstudio.github.io/keyboard-adults/sitemap.xml` у Google Search Console та Bing Webmaster Tools.

Canonical URL і картка поширення вже вказують на адресу GitHub Pages. Для GitHub Pages у підпапці файл `robots.txt` цього проєкту буде доступний за адресою `/keyboard-adults/robots.txt`; він не замінює кореневий файл `robots.txt` домену `briomusicstudio.github.io`. Якщо сайт буде перенесено на власний домен, перевірте canonical URL, sitemap і метадані поширення та розмістіть `robots.txt` у корені домену.
